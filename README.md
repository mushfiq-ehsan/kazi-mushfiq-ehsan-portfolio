## About

My personal portfolio, designed like a code editor. It presents who I am, what I've built, and how to reach me, in a clean dark interface with smooth, purposeful motion.

I'm a Front-End Developer at **Softvence Omega** (Wix Coders team), building responsive client-facing websites with React, Tailwind CSS, Firebase, and Wix/Velo. I'm currently expanding into Node.js and MongoDB.

<br />

## Features

| | |
|---|---|
| **Code-editor aesthetic** | Dark theme with terminal-style details and a consistent mint accent |
| **Smooth motion** | GSAP and ScrollTrigger animations with Lenis smooth scrolling |

## Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/mushfiq-ehsan/<repo-name>.git

# 2. Open the folder
cd <repo-name>

# 3. Start a local server (any static server works)
npx serve .
```

Then open the local address shown in your terminal. The site is plain HTML, CSS, and JavaScript, so there's no build step.
