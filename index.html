// about.md

I'm a motivated and adaptable Front-End Developer with hands-on experience building responsive, user-friendly web interfaces. I enjoy turning rough ideas into clean, functional products — from pet-care platforms to finance trackers — and I'm steadily growing into the full MERN stack. Outside of shipping features, I care about writing code that reads well and interfaces that feel effortless to use.

My day-to-day work centers on React.js, Tailwind CSS, and JavaScript (ES6+), building interfaces that stay fast and accessible across devices. I've worked extensively with Wix and Wix Studio on client projects, handling everything from custom layouts to Velo-based functionality, and I bring that same attention to structure and detail into my own React builds. I'm currently expanding into Node.js and MongoDB to round out a full-stack skill set, so I can take a project from database to browser without handing off the harder parts.

Based in Khilgaon, Dhaka, Bangladesh, I'm open to Front-End Developer roles — in-office, remote, or freelance — where I can keep learning while shipping work people actually use.
